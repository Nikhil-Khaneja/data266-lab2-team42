repository setup, scaffolding, implementation of the RAG pipeline (Part 1), diffusion
fine-tuning pipeline (Part 2), and multi-agent system (Part 3), plus documentation.

AI-assisted code and every reported number were verified are documented in
`part1/member-anushka/AI_USAGE.md`.

AI-assisted code was verified are documented in `part2/member-anushka/AI_USAGE.md`.
